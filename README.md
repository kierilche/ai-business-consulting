# AI Business Consulting Landing

Сайт для услуги внедрения AI в продажи, HR и бизнес-процессы, подготовленный к публикации на Vercel.

## Структура

- `index.html` — основная продающая страница
- `styles.css` — стили, адаптив, анимации и визуальная система
- `script.js` — анимации появления блоков и переход формы в Telegram
- `package.json` — npm-скрипты для локального запуска и сборки
- `server.js` — локальный dev-сервер без зависимостей
- `build.js` — сборка статического сайта в `dist`
- `vercel.json` — конфигурация для Vercel
- `ai-dlya-prodazh/index.html` — заготовка под SEO-страницу
- `ai-dlya-hr/index.html` — заготовка под SEO-страницу
- `ai-audit-biznesa/index.html` — заготовка под SEO-страницу
- `avtomatizaciya-prodazh/index.html` — заготовка под SEO-страницу
- `ai-v-voronezhe/index.html` — заготовка под региональную SEO-страницу

## Запуск локально

```bash
npm install
npm run dev
```

После этого откройте:

```text
http://127.0.0.1:3000
```

## Сборка

```bash
npm run build
```

Результат сборки будет в папке `dist`.

## Публикация на Vercel

1. Загрузить проект на GitHub
2. Подключить репозиторий в Vercel
3. Нажать Deploy

## Что готово

- адаптивный B2B-лендинг на русском языке
- hero-блок с акцентом на результат бизнеса, а не технологии
- блоки решений, кейсов, доверия, этапов работы и формы заявки
- основной CTA переведен в Telegram
- контакты обновлены: Telegram и телефон
- hover-эффекты, плавный скролл и мягкие анимации появления
- подготовлена структура под будущие SEO-страницы
- проект готов к деплою на Vercel
